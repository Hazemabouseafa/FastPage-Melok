- 💬 **زر واتساب طاير (Floating WhatsApp):** مع إشعار نبض تفاعلي وفقاعة تنبيه تفتح المحادثة المباشرة فوراً.

## 🚀 كيفية الرفع والربط على VPS باستخدام Coolify

المشروع مصمم ليعمل بضغطة زر واحدة على منصة **Coolify**:

### الطريقة الأولى: الربط المباشر مع GitHub (الموصى بها)
1. افتح لوحة تحكم **Coolify** على السيرفر (VPS) الخاص بك.
2. اضغط على **+ New Project** أو اختر المشروع الحالي.
3. اضغط على **+ New Resource** ثم اختر **Git Source (GitHub)**.
4. اختر المستودع: `Hazemabouseafa/FastPage-Melok`.
5. سيقوم **Coolify** تلقائياً باكتشاف الـ `Dockerfile`.
6. قم بتحديد الدومين الخاص بك (مثال: `zefaf.yourdomain.com`).
7. اضغط **Deploy**! سيقوم Coolify ببناء الحاوية وتفعيل شهادة SSL (HTTPS) تلقائياً في ثوانٍ.

### الطريقة الثانية: كـ Static Site
- في Coolify، يمكنك أيضاً اختيار نوع النشر **Static** واختيار الدليل الرئيسي `/` وسيعمل مباشرة عبر Caddy/Nginx المدمج في Coolify.

### الطريقة الثالثة: التشغيل المحلي بواسطة Docker
```bash
# بناء وتشغيل الحاوية
docker compose up -d --build

# الموقع سيعمل مباشرة على:
http://localhost
```
